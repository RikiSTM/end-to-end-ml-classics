Telco Churn MLOps

Telco Churn MLOps is a machine learning project by Riki Sutiaman, an AI/ML engineer with 10 years of QA experience. It implements an end-to-end machine learning workflow from EDA, Feature engineering to training and logging with MLFlow. The pipeline serves predictions to FastAPI endpoint and evaluate the model result with Explainable AI (XAI) and Bias and fairness test

Overview

This project addresses the high customer churn rate in the telecommunications industry by building a production-ready MLOps pipeline. It processes historical customer data, trains classification models, and serves real-time predictions via an API. The final pipeline ensures reproducibility, model reliability, and fairness in automated decision-making.

Key Techniques

  • Exploratory Data Analysis (EDA) & Feature Engineering on imbalanced telco data
  • Model training, logging, and experiment tracking using MLflow
  • Real-time inference API serving using FastAPI
  • Model explainability (XAI) and Bias/Fairness evaluation
